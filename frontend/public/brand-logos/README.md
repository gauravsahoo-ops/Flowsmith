# Flowsmith brand marks

These assets are self-hosted so the connector catalog works offline and never
depends on a third-party logo CDN at runtime.

Sources:

- **SVG Logos** (`@iconify-json/logos`, CC0) — primary source for multi-colour
  product marks.
- **Simple Icons** (`simple-icons`, CC0) — crisp monochrome fallbacks, tinted
  with the vendor colour from the package metadata.
- **Microsoft Fluent product icons** — Excel, Outlook, SharePoint, Teams and
  OneDrive product marks.
- **Wikimedia Commons** — Microsoft Dynamics 365 and Microsoft Entra ID marks.
- **Vendor favicons** — used only where no vector mark is available; stored
  locally and served from this directory.

All product names, logos, and brands are the property of their respective
owners. They are used here only to identify the integration a workflow
connects to. Their presence does not imply a partnership, endorsement, or
vendor certification.
